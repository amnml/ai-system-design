# AI System Design Experiments

A workspace for experimenting with AI system designs, architectures, and implementation patterns. This repository collects design diagrams and small demos to explore how different approaches work and the tradeoffs involved.

Experiments prioritize learning and simplicity over production readiness. Each design lives in its own folder, with its diagram, code, and setup instructions where available.

## Adding experiments

Create a folder for each new design and add an entry to the table above. Include a README explaining the problem, architecture, key tradeoffs, and how to run the demo. Keep diagrams and implementation files together so each experiment is easy to explore.
